# 基金守望

基金守望是一套面向个人使用的基金持仓与风险分析工具，可在安卓手机和电脑浏览器使用。它支持从支付宝基金截图辅助导入、手动录入份额与成本、查看基金详情，并按指数基金、债券基金、QDII基金分别给出可解释的持有/观察/分批买入/减仓复核提示。

> 重要：本项目不会登录支付宝、不会读取支付宝账号、不会自动买卖基金，也不承诺收益。最终交易必须由使用者本人在支付宝确认。

## 当前 MVP 已包含

- 手机和电脑响应式界面，可安装到安卓桌面作为 PWA 使用。
- 可选保守、稳健、进取或自定义风险模式，并设置计划投资总额、保留现金、亏损警戒线、投资期限和仓位上限。
- 支持基金搜索、详情、持仓、交易记录和支付宝截图辅助导入。
- 指数、债券、QDII分类分析，并显示每条结论的触发原因。
- 读取近20/60个净值点、最大回撤、当日估值、持仓盈亏和仓位比例。
- 工作日北京时间14:10生成交易窗口复核，21:10生成晚间日报。
- 通过 Server酱优先发送到微信；开关和提前提醒分钟数可在页面设置。
- Supabase云同步，手机和电脑使用同一邮箱验证码登录。
- GitHub Pages免费发布，日常使用只需打开网址或桌面图标，不需要打开GitHub。

## 分析规则

分析程序使用透明规则，不让一个不明来源的“AI答案”直接决定交易：

1. 持仓亏损达到个人警戒线时，标记“触发风险警戒”。
2. 单只基金或QDII仓位超过上限时，标记“评估分批减仓”。
3. 债券基金单日异常波动，或近60个净值点最大回撤越线时，标记“重点观察”。
4. 仍有计划资金、仓位未超限、短期回调但中期风险未越线时，标记“观察分批买入”。
5. 其余情况显示“继续持有”或“等待分批条件”。

这些结论只用于缩小需要人工核对的信息范围。QDII还会额外提示海外休市、汇率、限购和净值延迟；真正操作时间以支付宝显示的截止时间为准。

## 技术版本

- Node.js：项目要求 `>=20.9.0`；本机验证版本为 `24.19.0`。
- npm：本机验证版本为 `11.17.0`。
- Next.js：`16.1.6`（锁文件实际安装版本）。
- React：`18.3.1`。
- Supabase JavaScript：`2.x`。
- Tesseract.js：`5.1.1`。

## 本地运行

```powershell
npm ci
npm run dev -- --hostname 127.0.0.1
```

然后打开 `http://127.0.0.1:3000`。

## 免费部署所需服务

- GitHub：保存源代码、发布GitHub Pages、运行每日分析。
- Supabase：邮箱验证码登录和手机/电脑数据同步。
- Server酱 Turbo：把汇总结果推送到微信。

免费额度和平台规则可能调整，正式使用前应查看各平台当前说明。

## 隐私设计

- Supabase启用行级安全，每个登录用户只能读取自己的配置。
- 每日任务使用指定的用户UUID读取数据，不遍历全部用户。
- 持仓金额和基金明细不会打印到GitHub Actions日志。
- Supabase `service_role` 和 Server酱 SendKey只允许保存在GitHub Actions加密变量中。
- 默认不启用Google Analytics；已移除原项目的Sentry会话上报。
- GitHub Pages页面可以公开访问，但没有你的登录会话就不能读取你的Supabase持仓。
